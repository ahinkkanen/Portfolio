Tunnilla loimme Azure ympäristössä meidän jo luodulle virtuaalikoneellemme ohjauspalvelimen. Konfiguroimme ohjauspalvelinta meidän tarpeisiimme soveltuvaksi. Määritimme erikseen prosessorin ytimien määrät sekä muistin kokonaiskapasiteettia. Sitten käynnistimme sen ja aloimme suorittamaan seuraavan asteen konfigurointia Server Managerin kautta. Asetimme määreet Ethernet-verkkokortille (määritimme IP-osoitteen, verkkomaskin ja oletusyhdyskäytävän). Sen jälkeen määritimme ohjauspalvelimen IP verkkoavaruustyypin. Ajoimme komento rivillä komentoja, joilla saimme aktivoitua ohjauspalvelimen käyttöjärjestelmän.
Työelämässä varmasti tulen jossain muodossa käyttämään Azure ympäristöä. Tämän kurssin aikana kerrytetyllä osaamisella voin varmasti sanoa, että olen tutustunut järjestelmään ja osaan hallita asioita sekä ymmärrän perustason toimintoja pilviympäristössä. Myös koen ymmärtäväni konkreettisia etuja mitä tällaiset pilviympäristöt ja virtuaalikoneet mahdollistavat yrityksille.
