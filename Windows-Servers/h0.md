virtuaalisen Azure ympäristön, johon otimme yhteyttä. Azure ympäristössä asensimme
Hyper-v ohjelmiston. Opin ymmärtämään kokonaisuutta enemmän ja miten asiat
pilviympäristössä toimivat. Uskon voivani hyödyntää näitä taitoja, sekä jatko
jalostamaan niitä.
